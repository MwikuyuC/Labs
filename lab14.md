## Теоретическая часть

### Семафоры в UNIX

Семафоры — это механизм синхронизации процессов, позволяющий организовать доступ к общим ресурсам. В данном лабораторной работе реализуется упрощённый механизм семафоров с использованием файловых блокировок.

### Переменная $RANDOM

Встроенная переменная `$RANDOM` в bash генерирует псевдослучайные целые числа в диапазоне от 0 до 32767. Используется для создания случайных последовательностей.

### Структура man-страниц

Справка по командам хранится в каталоге `/usr/share/man/man1/` в сжатом виде (файлы с расширением `.1.gz`). Для просмотра используется команда `zcat` или `less`.

## Ответы на контрольные вопросы

### 1. Найдите синтаксическую ошибку в строке `while [$1 != "exit"]`

**Ошибка:** Отсутствуют пробелы вокруг квадратных скобок.

**Правильный синтаксис:**
```bash
while [ "$1" != "exit" ]
```

### 2. Как объединить (конкатенация) несколько строк в одну?

```bash
# Способ 1: Простое объединение
result="$str1$str2"

# Способ 2: Использование +=
result=""
result+="$str1"
result+="$str2"

# Способ 3: Использование printf
result=$(printf "%s%s" "$str1" "$str2")
```

### 3. Найдите информацию об утилите seq. Какими иными способами можно реализовать её функционал?

**seq** генерирует последовательности чисел.

**Альтернативы:**
```bash
# Цикл for
for ((i=1; i<=10; i++)); do echo $i; done

# Brace expansion
echo {1..10}

# Цикл while
i=1; while [ $i -le 10 ]; do echo $i; i=$((i+1)); done
```

### 4. Какой результат даст вычисление выражения `$((10/3))`?

**Результат: 3** (целочисленное деление)

### 5. Укажите кратко основные отличия командной оболочки zsh от bash

| Характеристика | bash | zsh |
|----------------|------|-----|
| Автодополнение | Базовое | Расширенное |
| Исправление опечаток | Нет | Есть |
| Рекурсивный поиск | Нет | Есть (`**/`) |
| Индексация массивов | С 0 | С 1 |

### 6. Проверьте, верен ли синтаксис конструкции `for ((a=1; a <= LIMIT; a++))`

**Синтаксис верен.** Это C-подобный цикл for в bash.

### 7. Сравните язык bash с другими языками программирования

**Преимущества bash:**
- Простота автоматизации задач ОС
- Прямой запуск команд
- Высокая переносимость

**Недостатки bash:**
